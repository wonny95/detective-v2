# 바뀐 소풍 가방 · 장면 배경

`design/case-01-picnic-bag.html`의 장면 00–08에 각 한 장씩 사용한다. 이 그림들은 기획안의 장면 배경이며, 새 사건은 아직 게임에 구현되지 않았다.

- 제작: Codex, Higgsfield Nano Banana 2.1, 16:9·1K·thinking high, 장당 1.5크레딧(9장 약 13.5크레딧).
- 공통 화풍 참조: 도서관 원화의 Higgsfield job `5af42d02-7245-4f52-bec3-251e60f26c13`. 따뜻한 크림색 종이, 가는 손그림 윤곽, 색연필·과슈 질감, 목재와 청록색 소품. 인물·UI·읽을 수 있는 글씨는 프롬프트에서 제외했다.
- 원본 생성 크기: 모두 1376×768 PNG. 웹 페이지용으로 WebP 품질 90으로 변환해 9장만 저장했다. PNG 원본은 아래 job에서 다시 받을 수 있다.

| 장면 | 파일 | 배경 내용 | Higgsfield job |

| 01 의뢰 | `scene-01.webp` | 소풍 탁자와 닫힌 파란 가방 | `60cd4fc1-38d2-4680-a032-cf5f71f062c9` |

| 03 카페 | `scene-03.webp` | 호수 카페 실내, 열린 가방의 빨간 도시락·노란 물병 | `3413f124-412d-4deb-8c03-a78522117ded` |

01의 생성 그림을 02·06·07의 추가 참조로, 03의 생성 그림을 07의 추가 참조로 사용해 장소와 가방 모양을 연결했다. 기획안에는 정답이 보이지만 실제 플레이에서는 02·03의 물건이 현장 촬영으로만 기록되고, 07의 양쪽 가방은 추리 뒤에만 등장해야 한다.
