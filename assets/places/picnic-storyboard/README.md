# 바뀐 소풍 가방 · 장소 배경

`design/case-01-picnic-bag.html`은 **소풍 탁자·정원 각 한 장**과 도서관 사건에서 쓰는 기존 호수 카페 배경 `../cafe-higgsfield.png`를 사용한다. 같은 장소를 다시 방문하거나 다른 장면에서 보여 줄 때 같은 배경을 재사용한다. 준비·추리·복습은 별도 장소 그림을 만들지 않는다. 새 사건은 아직 게임에 구현되지 않았다.

| 장소 | 파일 | 화면에 있는 단서 | 사용 장면 | Higgsfield job |
|---|---|---|---|---|
| 소풍 탁자 | `picnic.webp` | 열린 파란 가방, 초록 도시락, 파란 물병 | 01·02·06·07 | `a13b9d3f-5211-48fe-9e4f-fa2f1789428f` |
| 호수 카페 소품 참고 시안 | `cafe.webp` | 열린 파란 가방, 빨간 도시락, 노란 물병. 장면 배경으로 사용하지 않음 | 카페의 별도 가방 소품·촬영 프레임 참고 | `b33d63ae-7e89-4da1-8c44-678173424197` |
| 정원 | `garden.webp` | 꽃길과 빈 벤치. 인물의 물건 없음 | 04 | `ed423a34-161b-4c5a-885d-0aa17620a3ff` |

- 제작: Codex, Higgsfield Nano Banana 2.1, 16:9·1K·thinking high, 1376×768. 기존 해당 장소 원화를 참조해 벽·바닥의 크레용 낙서, 별·소용돌이 장식, 바닥에 떨어진 크레용을 제거했다. 자연스러운 목재 결·꽃·잎과 색연필·과슈 질감은 유지했다.
- 생성 비용: 장소 3장에 약 4.5크레딧, 소풍 탁자 바닥의 남은 별 낙서 수정 1장에 약 1.5크레딧(이번 수정 합계 약 6크레딧). 웹 표시용 WebP 품질 90으로 저장했다. 카페 그림은 제작 기록으로 보관하고, 실제 스토리보드 장면에는 기존 카페 배경을 수정 없이 재사용한다. 카페 가방·물건은 배경 위에 별도 조사 소품으로 배치할 계획이며 아직 게임용으로 분리하지 않았다. 원본 PNG는 위 job에서 다시 받을 수 있다.
- 장면 07은 소풍 탁자 배경을 재사용한다. 두 번째 가방은 실제 게임을 만들 때 별도 오브젝트로 배치한다. 인물·질문·증거 확대·결과 UI도 배경 위에 별도로 놓는다.
