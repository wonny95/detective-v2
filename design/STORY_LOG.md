# 스토리 기획 기록

스토리 기획(Codex, `E:\GPT\Pioo-story`, 브랜치 `story`)의 작업 기록이다. 개발 기록은 `CHANGELOG.md`에 있다. 분업과 절차는 `AGENTS.md`를 따른다. **새 항목은 맨 위에 추가한다.**

항목 형식:

```
## YYYY-MM-DD HH:MM · Codex · 커밋
- 바꾼 기획 (사용자가 정한 것은 "사용자 결정"이라고 적는다)
- 확인: 설계서끼리 맞춰 본 것 / 못 한 것
- 개발 요청: 게임에 넣을 것과 설계서의 위치(예: `design/case-01-picnic-bag.md` 대본 표). 없으면 "없음"
- **다음**: 기획 쪽이 이어서 할 일. 없으면 "사용자 지시 대기"(후보 2–3개를 적어 둔다)
```

- 개발이 요청을 반영하면 `CHANGELOG.md`에 "기획 반영: STORY_LOG <날짜>"로 적는다. 개발이 기획에 묻거나 설계서와 다르게 만든 것은 `CHANGELOG.md`의 **기획 요청**에 있다.
