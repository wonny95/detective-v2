# Case 03 곰 마을 꿀 가게 강도 — 몽타주 (설계서 초안)

상태: 초안 2판, 사용자 검토 중. 사용자 결정은 아래에 "사용자 결정"이라고 적은 것뿐이다.

## 사용자 결정 (2026-11-18)
- 연(01)·우산(02) 다음에 새 Case 03으로 넣는다. 소풍 이후는 한 칸씩 뒤로 미룬다.
- 곰들이 사는 마을의 강도 사건. 목격자 3명이 용의자의 특징을 2–3개씩 말한다.
- 노트 받아쓰기 대신, 들은 특징을 바로 몽타주 그림으로 맞춘다. 부위마다 좌우 화살표로 그림을 넘겨 정답을 고른다.
- 화면 배치는 사용자 스케치: 위에 말풍선(얼굴 아이콘 + 대사), 아래에 몽타주 액자, 얼굴 양옆에 화살표.
- 계획 추천안 승인: 한 문장씩 진행(대사가 가리키는 부위가 자동으로 골라짐), 연필 스케치 느낌의 SVG 부위(뒤에 Higgsfield 그림으로 바꿈), 결말은 경사에게 몽타주를 건네는 보고 방식.
- 특징은 더 구체적으로. 사용자 스케치의 모습을 그대로 정답으로 쓰지 않는다.

## 한 줄 요약
꿀 가게에서 돈통을 들고 달아난 곰이 있다. 오소리 경사의 부탁으로 탐정이 목격자 세 명의 말을 듣고 범인의 몽타주를 완성해 건넨다.

## 풀이 방식 (이 사건의 하나뿐인 풀이)
- 목격자를 누르면 몽타주 화면이 열린다. 목격자는 특징을 한 문장씩 말한다.
- 문장이 나오면 그 문장이 가리키는 부위가 반짝이며 골라진다. 플레이어는 ◀ ▶로 그 부위의 그림을 넘기고 "이 모습이에요"를 누른다.
- 특징 문장 하나에 알아들을 말이 두 개씩 있다(예: green cap + yellow star). 보기는 그중 하나만 다른 그림으로 채워서, 한 단어만 듣고는 고를 수 없게 한다.
- 맞으면 목격자가 맞다고 하고 그 부위가 고정된다(흐리던 그림이 진해짐). 틀리면 목격자가 "No."와 함께 같은 특징을 다시 말한다. 몇 번이든 다시 고를 수 있다.
- 다시 듣기와 해석 버튼은 지금처럼 쓴다. 해석은 문장을 맞힌 뒤에만 보여 줄지(듣기 우선) 사용자 확인 필요.
- 세 목격자의 순서는 자유다. 몽타주는 목격자 사이에서 그대로 이어진다.
- 7부위를 모두 맞추면 경사에게 건네기 버튼이 나온다.

## 진실 (제작자용)
- 범인은 갈색 털의 곰. 작은 눈에 굵은 눈썹, 눈 위에 흉터, 금니 하나. 한쪽 귀에 반창고. 노란 별이 달린 초록 모자, 흰 물방울무늬 빨간 목도리, 주머니 두 개 달린 조끼.
- 아침에 꿀 가게 계산대에서 돈통을 집어 들고 뛰어 나갔다.
- 목격자마다 본 위치가 달라서 말할 수 있는 특징이 다르다.
  - 브루노(가게 주인)는 계산대 앞에서 얼굴을 정면으로 봤다 → 눈·눈썹, 흉터, 이.
  - 토비(연 사건 아기 곰)는 가게 앞에서 놀다 뛰어가는 뒷모습을 봤다 → 모자, 귀.
  - 베티(도서관 사서)는 길 건너 도서관 창문에서 봤다. 멀어서 얼굴은 못 봤다 → 목도리, 조끼.
- 왜 탐정인가: 마을 경찰서에 그림 그릴 사람이 없다. 목격자들 말이 조각조각이라 하나로 모아야 한다.
- 범인을 잡는 장면은 보여 주지 않는다. 경사가 수배 전단을 만들겠다고 하며 끝난다(일부러 남김, 다음에 이어 쓸 수 있음).

**반응 대사**
- 맞음(목격자마다 하나): 브루노 "Yes! That's right." / 토비 "Yes! Just like that!" / 베티 "Yes, that's it."
- 틀림: "No." + 그 특징 문장을 다시(예: "No. He has small eyes and thick eyebrows."). 특징 7개 × 1줄.
- 목격자의 마지막 특징을 맞히면 끝맺음: 브루노 "That's the bear!" / 토비 "That's all I saw." / 베티 "I couldn't see his face." — 셋이 서로 다름.

## 몽타주 부위와 보기
첫 화면은 모든 부위가 정답이 아닌 그림으로 시작한다. 보기는 부위마다 5개(사용자 요청: 처음 2개 → 6개, 그림으로 바꾸며 5개), 정답에서 한두 가지만 바꾼 것으로 채운다. 정답은 굵게.

| 부위 | 보기 | 알아들어야 하는 것 |
|---|---|---|
| 눈·눈썹 | **작은 눈 + 굵은 눈썹** / 작은 눈 + 가는 눈썹 / 큰 눈 + 굵은 눈썹 / 큰 눈 + 가는 눈썹 / 졸린 눈 + 굵은 눈썹 | small–big, thick–thin |
| 흉터 | **눈 위**(보는 사람 왼쪽, 수배 전단과 같은 쪽) / 눈 아래 / 코 위 / 뺨 / 입 옆 | above(위) 와 위치 명사 eye |
| 이 | **금니 하나** / 금니 둘 / 은니 하나 / 빠진 이 / 보통 이 | only one gold tooth (하나, 금) |
| 모자 | **초록 모자 + 노란 별** / 초록 모자 + 흰 별 / 초록 모자, 별 없음 / 빨간 모자 + 노란 별 / 파란 모자 + 노란 별 | 색 둘 + 모양(cap) |
| 귀 | **한쪽 귀에 반창고** / 양쪽 귀에 반창고 / 한쪽 귀가 찢어짐 / 귀걸이 / 보통 귀 | bandage, one ear |
| 목도리 | **빨강 + 흰 물방울** / 빨강 + 흰 줄무늬 / 빨강, 무늬 없음 / 파랑 + 흰 물방울 / 초록 + 흰 물방울 | 바탕색·무늬색·무늬 |
| 조끼 | **조끼 + 주머니 둘** / 조끼 + 주머니 하나 / 조끼 + 주머니 셋 / 주머니 없는 조끼 / 재킷 + 주머니 둘 | vest, two |

## 학습
- 열쇠 표현: 생김새는 **has**, 옷차림은 **was wearing**. 연 사건의 is/has(물건 생김새)에서 사람 생김새로 넓힌다. 덧붙여 꾸밈 **with**(a cap with a yellow star).
- 들리는 횟수: has — 특징 4 + 틀림 반응 4 = 최대 8번. was wearing — 특징 3 + 틀림 반응 3 = 최대 6번. with — 특징 3. 모두 3번 이상.
- 복습 예문(사건 밖): "My cat {has} green eyes." / "She {was wearing} a yellow coat." / "The dog {has} long ears."
- 복습 단어: thick, eyebrows, scar, above, gold, tooth, bandage, scarf, dots, vest, pockets (모두 특징 문장에서).

## 확인하지 못한 것
- 실제 플레이, 소요 시간, 학습 효과: 검증 안 함.
- 한 문장에 알아들을 말이 둘 이상이라 L1에 어려울 수 있음. 대안: 틀림 반응에서 다른 부분만 강조해 다시 말하기(예: "No. His eyebrows are thick.").
- was wearing(과거진행)이 L1에 이른지. 대안: 옷도 "He has a red scarf."로 통일.
- 흉터·금니가 아이들에게 무섭지 않은지(만화 느낌으로 그릴 예정).
