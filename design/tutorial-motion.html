튜토리얼 움직임 시안

실제 게임 안의 튜토리얼 팝업이에요. 모든 장(1–7)이 그림 대신 게임의 버튼·노트·단어 카드를 그대로 써서, 누르는 동작을 짧게 반복해서 보여 줘요. 내용은 사건과 무관한 예문이에요.

누르는 손가락은 탐정의 오른쪽 앞발(오른손 2, 사용자 결정)이에요.

3장은 기록 완료 → 틀린 칸이 흔들리고 다시 확인 → 다시 듣기 → 고치기 → 다시 확인(초록, ✓ 확인됨) → 닫기 → 새 장소 알림까지 게임의 실제 움직임 그대로예요.

4–6장도 같은 방식이에요: 4장 지도 → 현장 → 옆으로 밀기 → 사진 찍기, 5장 증거 → 📌 → 메모, 6장 추리 빈칸 → 경찰에게 알리기, 7장 심문에서 증거 내밀기(사건과 무관한 예시).
