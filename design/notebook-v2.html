노트 개편 시안

Note를 연 모습이에요. 위 탭은 인물 · 증거 · 메모 세 개로 고정이에요. 인물은 노트 제목을 눌러 여는 인물 메뉴로 바꾸고, ‹ ›로 앞뒤 인물로 넘겨요. 📌로 진술·증거를 메모에 붙이고, 메모에 내 생각을 적어요.

1. 탭 3개로 고정 (사용자 선택)

  • 노트 위 탭은 언제나 인물 · 증거 · 메모 세 개. 인물이 몇 명이 되어도 늘지 않는다. 그림은 지금의 손그림 종이 탭 그대로, 아이콘만(사용자 요청: 가로가 좁다; 글자는 접근성 이름으로만). 탭 폭 50px.
  • 옆 인덱스 탭은 넣지 않는다(사용자: 화면이 좁다).

2. 인물 메뉴 (사용자 아이디어)

  • 인물 탭의 노트 제목 줄이 곧 메뉴다: [얼굴] Sgt. Badger의 진술 ▾. 누르면 제목 아래로 종이 메뉴(말풍선 종이 + 연필 꼬리, 추리 칠판의 드롭다운과 같은 모양)가 펼쳐지고, 만난 인물이 큰 얼굴 + 작은 이름으로 4열. 얼굴 모서리에 진행(✓ 다 기록 / 1/3), 지금 인물은 꿀색 종이.
  • 제목 오른쪽 ‹ ›로 앞뒤 인물로 바로 넘긴다(만난 순서). 메뉴 밖을 누르면 닫힌다.
  • 공간: 제목 줄은 지금도 있는 자리라 노트 글 영역이 한 줄도 줄지 않는다. 비교용 "얼굴 줄"은 얼굴 한 줄(약 70px)만큼 글이 줄어든다.
  • 대화 중(받아 적는 중)에는 지금처럼 그 질문만 보이고, 대화가 끝날 때까지 메뉴는 지금 인물에 고정(대화 잠금과 같은 원칙).

3. 메모

  • 자유 메모: 줄 노트에 직접 쓴다. 사건마다 저장(이어서 수사 때 그대로), 추리 칠판에서 Note를 열어도 보인다.
  • 📌 붙이기: 진술 질문 옆, 증거 사진 모서리의 📌를 누르면 메모 위쪽에 쪽지로 붙고 메모 탭에 숫자가 톡 뜬다. 다시 누르거나 메모에서 ×로 뗀다.
  • 메모 글은 플레이어가 쓴 것이라 게임 규칙(사건 정보는 대화·증거로만)과 부딪히지 않는다. 안내 문장(빈 메모의 예시 글 등)은 넣지 않는다.
  • 나중 후보: 용의자 도장(○ △ ✕ + 한 줄), 시간표 메모.

4. 탭 색 (사용자 요청: 열린 탭이 잘 구분되지 않음)

  • 종이로 이어짐(추천): 열린 탭은 노트 종이와 같은 크림색이고, 폴더의 파란 테두리를 덮고 내려와 종이와 한 장처럼 이어진다. 나머지 탭은 폴더와 같은 파란색에 크림색 글자, 더 낮고 뒤에. 진짜 인덱스 탭처럼 "지금 이 장"이 바로 보인다.
  • 탭마다 색: 인물 하늘색 · 증거 연두 · 메모 꿀색. 열린 장의 제목 줄과 위쪽 띠가 같은 색이 되고, 나머지 탭은 흐려진다. 색으로 장을 기억하기 쉽지만, 노트 종이 자체는 크림색 그대로라 이어지는 느낌은 약하다.
  • 폴더 그림의 클립은 지웠다(사용자 요청: 오른쪽 위 UI를 가림). 원본은 assets/ui/casefile-panel-with-clip.webp. 같은 그림을 게임 노트도 쓰므로 게임에서도 클립이 사라졌다.

5. 정할 것

  1. 인물 메뉴(4열 얼굴)로 갈지, 얼굴 줄이 나은지.
  2. ‹ › 넘기기를 둘지.
  3. 메모를 사건마다 따로 둘지(제안), 모든 사건에 하나로 둘지.
  4. 탭 색: 종이로 이어짐(추천) / 탭마다 색.
