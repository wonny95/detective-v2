# 화단 사건 전체 흐름 점검

2026-11-04 · 사용자 요청에 따른 대본·학습·해금 점검. 이 문서의 원점검은 수정 전 기록이다. 사용자 요청으로 아래 0절의 개선을 반영했으며, 개발 인계나 원화·실제 플레이 검증은 아직 하지 않았다. 기준은 현재 [상세 대본](case-flowerbed-ball.md)과 [장면별 기획](case-flowerbed-ball.html)이다. [점검 화면](case-flowerbed-review.html).

수정 전 점검 요약: 큰 줄기는 의뢰 → 정상 상태 확인 → 주변 인물 탐문 → 서로 다른 위치 진술 대조 → 거스에게 재확인 → 올리 보고로 연결된다. 다만 **정원 출입과 꽃 훼손 사이의 연결, 거스의 이른 부인, 시점의 출처, 루카를 제외하는 목격 범위, 필수 촬영의 역할, 목표 표현을 묻는 추리**는 보완할 필요가 있다. 실제 게임·원화·녹음으로 검증한 결과가 아니라 설계서 검토 결과다.

## 조사 연결 변경 반영 · 2026-11-09

사용자 승인으로 피아의 카메라 목격 → 루카의 촬영 진술 → 벤치의 친구 렌 발견으로 대본·미리보기·흐름도를 맞췄다. 루카 l3 질문과 노트 2칸을 추가해 현재 16문항·40칸, Did 질문 10회다. 답변 평균10.7·최장15단어이며 기본 분량 초과 이유를 설계서에 적었다. 아래 재점검의 피아 도입·거스 허락 문구 제안 두 곳은 아직 적용하지 않았다. 개발 미인계 유지.

## 최신 재점검 · 2026-11-09

이전 주요 7항목의 개선이 현재 대본에 반영된 상태를 기준으로 재검토했다. 이번에는 원본 대본·미리보기·흐름도를 수정하지 않았다. 아래 두 대화 수정은 제안이며, 두 공간 항목은 원화 제작 시 확인할 조건이다. 개발 미인계 유지.

올리의 의뢰 → 정상 상태 사진 → 피아의 작업 설명 → 거스·루카의 서로 다른 주장 → 렌의 목격 → 거스의 정원 출입 인정 → 공 위치·회수 경로와 현장 대조 → 훼손 인정 → 올리 보고로 연결된다. 정원 출입과 꽃 훼손은 분리했고, 공의 소량 흙만으로 범행을 단정하지 않는다. 공 사진 없이도 진행 가능하며 렌의 조건부 질문에 문서상 순환 잠금은 발견하지 못했다. 현재 해결 구조를 바꿔야 할 확정 오류는 발견하지 않았다.

## 2. 작은 설정·자료 문제

| 항목 | 근거 | 검토할 방향 |
|---|---|---|
| 당일 사진이 이미 인쇄돼 있음 | 오전에 찍은 사진을 같은 날 오후 펼친 작업일지의 인쇄 사진으로 보여 준다. 인쇄한 경위는 없다. | 휴대전화·카메라에 있는 사진을 보여 주는 설정처럼 불필요한 인쇄 과정을 없애는 편이 자연스럽다. 사건 날짜를 바꿔 시간 논리를 깨지는 않는다. |

## 3. 현재 잘 이어지는 부분

- 올리가 직접 의뢰하고 결과를 듣는다. 일상적인 사고에 경찰이 개입하거나 후보 전원을 모으는 장면은 없다.
- 피아는 참고인으로 작업 이야기를 하고 주변 친구를 소개한다. 꽃을 심었다는 이유만으로 범인 후보에 넣지 않는다.
- 거스와 루카는 서로 다른 이유로 정원에 접근했다. 함께 공놀이한 공범 설정은 없다.
- 렌은 공의 착지나 꽃을 밟는 순간을 봤다고 말하지 않는다. 마지막 훼손 확정은 거스의 인정 뒤다.
- 공에는 소량의 흙만 남는다. 꽃잎·개별 발 모양·종이나 외모로 범인을 고르는 단서는 없다.
- 질문은 선택지이고 노트는 실제 답변을 그대로 인용한다. 조건부 렌 질문이 잠겨 있어도 첫 방문을 끝낼 수 있으며, 문서상 해금 순환은 발견되지 않았다.
- 결말은 거스의 인정·복구 의사 → 탐정의 수동 이동 → 올리에게 보고다. 꽃이 즉시 원상복구되거나 공을 강제로 가져가는 동작은 없다.

## 6. 결정·가정·미확인

- **사용자가 결정할 것**: 우선 항목 1–7의 수정 방향 채택 여부, 공 사진의 필수 여부, 사건 번호·L1-06 A/B 편입·기존 사건 대체 여부. 이번 점검 요청은 이 선택들이 결정됐다는 뜻이 아니다.
- **제작자용 가정**: 공이 화단 안의 빈 흙에 떨어졌고 거스가 회수하며 꽃을 밟음, 렌이 루카 촬영 전 구간을 봄, 올리가 현장을 지키고 피아가 모종을 준비함. 실제 플레이에서는 필요한 사실을 대사·증거로 확인해야 한다.
- **확인한 것**: 현재 MD·HTML과 규칙 대조, 질문·빈칸·분량·열쇠 수 재계산, 답변과 노트 인용·정답 보기·HTML 고유 ID·내부 링크·중첩 확인. 해금 그래프는 문서상 도달 가능하며 순환 잠금 없음.
- **확인하지 못한 것**: 실제 플레이·엔진 지원·원화 시야·실제 음성 청취·소요 시간·학생 학습 효과는 **검증 안 함**. 대본과 개발 파일은 수정하지 않았다.

**다음**: 점검 내용을 사용자와 검토하고 승인받은 수정만 반영한다. 개발 인계는 별도 사용자 지시가 있어야 한다.
